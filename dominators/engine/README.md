# Игровое состояние и правила — этап 02

Этот каталог — место для правил, не зависящих от отрисовки.

## Текущая модель прототипа

- Энергия аккумулятора: 0–100 условных единиц.
- Ползунок распределения задаёт долю мощности движения; остаток назначается щиту.
- Тестовый удар уменьшает заряд аккумулятора на 10 единиц.
- Нулевой заряд сигнализирует критическое состояние; полноценная система разрушения модулей пока не реализована.

## Следующий инженерный шаг

Вынести значения и переходы состояния в отдельный модуль, добавить автоматические проверки и подключить его к сцене. Не смешивать условные игровые единицы с физическими единицами СИ без явного преобразования.
