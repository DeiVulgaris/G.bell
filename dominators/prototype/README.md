# Dominators Prototype

Интерактивная 3D-сцена на Three.js.

- Ограниченная сферическая сцена с центром в начале координат.
- Сферическая сетка задаёт границы пространства.
- В центре расположен 3D-проектор планетария.
- Внутри сферы размещены звёзды и модель планетной системы.
- Камера вращается и приближает сцену с помощью мыши.

Откройте `index.html` через локальный HTTP-сервер или GitHub Pages. Three.js загружается из CDN.
