# Прототип 01 — Доминаторы

Это первый самостоятельный браузерный прототип, без сборки и дополнительных библиотек.

## Запуск

Откройте [index.html](./index.html) в современном браузере. Можно скачать файл и открыть локально.

## Что уже работает

- процедурное звёздное поле и простая перспективная сцена с объектами системы;
- выбор объекта кликом;
- `Shift + клик` по объекту включает прототип автопилота, который удерживает цель около центра курса;
- наведение курсором управляет взглядом, когда автопилот не захвачен;
- тактический радар с условными позициями объектов;
- ползунок распределения энергии и сканера;
- тестовый удар по щиту с уменьшением заряда аккумулятора;
- сброс сцены.

## Ограничения версии

Это визуальный прототип, а не полноценная 3D-физика. Орбиты, дистанции, скорость и радар пока условные; ползунок сканера пока отображает дальность, но не фильтрует объекты. Энергетическая модель упрощена. Следующий этап — разделить игровое состояние и визуализацию, затем заменить условную перспективу на полноценный 3D-движок.
