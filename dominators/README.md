# Доминаторы — отдельный игровой проект

Эта папка содержит прототип игры «Доминаторы» внутри репозитория G.bell.
Код основного приложения находится отдельно; игровые эксперименты ведём здесь.

## Структура

- `prototype/` — запускаемый игровой прототип и интеграция рендера.
- `engine/` — игровые правила, физические модели и расчёты.
- `systems/` — звёздная система, орбиты и игровые объекты.
- `cockpit/` — управление, HUD, радар и автопилот.
- `docs/` — спецификации, решения и журнал изменений.

## Принципы разработки

1. Не менять код G.bell вне этой папки без отдельной необходимости.
2. Сначала создавать маленький проверяемый прототип, затем расширять его.
3. Разделять игровые правила, управление и визуализацию.
4. Не считать условные игровые модели подтверждённой физикой реального мира.

Рабочая ветка: `dominators-prototype`.
