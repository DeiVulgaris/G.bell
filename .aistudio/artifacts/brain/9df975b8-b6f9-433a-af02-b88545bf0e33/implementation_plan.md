# Модульная система кораблестроения (6-осевой каркас XYZ) и Орбитальная Верфь-Конструктор

Комплексная архитектура кораблестроения на основе универсального 6-лучевого стыковочного блока (+X, -X, +Y, -Y, +Z, -Z), позволяющая собирать корабли любой конфигурации: от линейных крейсеров и тяжелых тягачей до многоядерных модульных платформ с интерактивным 3D-конструктором на орбитальной верфи.

---

## User Review & Critical Decisions

> [!IMPORTANT]
> Ниже зафиксированы ключевые принципы и предложенные инженерные стандарты модульного конструирования.

- **Единый базовый строительный элемент**: **Стыковочный модуль (6-лучевой хаб)**.
  - Геометрия: центральная силовая сфера диаметром $D$, из которой выходят 6 цилиндрических туб вдоль координатных осей: `+X` (правый борт), `-X` (левый борт), `+Y` (верх / дорсальный), `-Y` (низ / вентральный), `+Z` (нос / передний), `-Z` (корма / задний).
  - На конце каждого луча расположен универсальный магнитный/гравитационный шлюз-коннектор.
- **Многоядерность и цепочки хабов**:
  - К любому из 6 узлов можно пристыковать либо функциональный модуль, либо **следующий стыковочный блок**.
  - Это позволяет собирать каноническую компоновку, предложенную пользователем:
    `[Блок двигателей с 5 дюзами]` $\to$ `[Блок солнечных крыльев]` $\to$ `[Блок радаров/приборов]` $\to$ `[Блок грузовых трюмов]` $\to$ `[Блок оружия]` $\to$ `[Модуль пилота с рубкой и каютой]`.
- **Специализация модулей и сферы двигателей**:
  - **Двигатели**: Сферический генератор импульса с выходной дюзой (реактивная плазменная, фотонная, ионная, гравитационная).
  - **Энергетика**: Спаренные солнечные крылья и радиаторы охлаждения.
  - **Приборы**: Сканеры, радары кругового обзора, антенны дальней связи.
  - **Трюмы**: Стандартизированные герметичные контейнеры (40т / 80т) и цистерны.
  - **Оружие**: Импульсные лазеры, плазменные пушки, торпедные пилоны.
  - **Командный блок**: Пилотская рубка с панорамным бронефонарем, каюта, библиотека и узел связи.

## 1. Overview & Core Concept

### Что это даёт игроку
1. **Истинная свобода космической инженерии**: Игрок больше не привязан к монолитным корпусам. Корабль собирается из физических блоков, каждый из которых влияет на массу, центр тяжести, распределение энергии, дальность радара, вместимость трюма и огневую мощь.
2. **Интерактивная Орбитальная Верфь (3D Shipyard Builder)**:
   - Полноценная 3D-сцена с вращением корабля, панорамированием и масштабированием.
   - Визуализация свободных стыковочных портов (подсвеченные маркеры-фланцы).
   - Клик по узлу открывает панель выбора доступных компонентов: пристыковать двигатель, крыло, радар, трюм, орудие, рубку или добавить ещё один стыковочный хаб для ветвления/удлинения корабля.
3. **Готовые заводские проекты + Свободный кастом**:
   - Пресет «Канонический Модульный Эксплорер» (ровно по описанию пользователя: кормовой пучок двигателей $\to$ энергоблок $\to$ радарный отсек $\to$ трюм $\to$ боевой отсек $\to$ рубка пилота).
   - Пресет «Тяжёлый Буксир» (2 ряда двигателей, 4 трюма).
   - Пресет «Патрульный Корвет» (скоростные ионные дюзы, спаренные лазеры).
   - Режим свободного проектирования с сохранением чертежей (Blueprints) в бортовой компьютер.

### Визуальный стиль 3D-моделей (Аутентичный векторный каркас)
- **Стыковочный блок**:
  - Центральная сфера с меридианами и шиной питания (тёмный металл корпуса + бирюзовый векторный каркас).
  - 6 цилиндрических туб со стяжными кольцами жесткости.
  - Концевые фланцы: кольцевые стыковочные шлюзы с янтарно-бирюзовыми направляющими огоньками.
- **Двигатели (Сфера с дюзой)**:
  - Сферический реакторный отсек с радиальными охлаждающими рёбрами.
  - Дюза в форме раструба Лаваля. Внутри дюзы — световое сопло:
    - Реактивная: огненно-оранжевое свечение факела.
    - Фотонная: ослепительно-бело-голубой световой луч с квантовыми кольцами.
    - Ионная: бирюзово-фиолетовая плазменная ионизация.
- **Солнечные батареи**:
  - Раскладные спаренные ферменные крылья с фотоэлектрической сеткой и золотистыми токосъёмниками.
- **Приборы**:
  - Сферический купол РЛС с вращающейся фазированной решёткой либо параболическая антенна ДРЛО.
- **Грузовой трюм**:
  - Прочный шестигранный или цилиндрический контейнер со строповочными замками и индикатором загрузки.
- **Модуль пилота**:
  - Каплевидная или гранёная кабина с 6-секционным остеклением, рабочим местом штурмана и шлюзом перехода в жилую каюту.

## 3. Key Product Decisions & Trade-Offs

- **Структура данных: Древовидный граф (Node Tree)**:
  - Каждый узел имеет уникальный `id`, координаты в локальной сетке `(gridX, gridY, gridZ)`, ориентацию и тип установленного модуля.
  - Корневой узел — первичный хаб `(0, 0, 0)`.
  - Пристыковка нового хаба создаёт дочерний узел в направлении выбранной оси, открывая ещё 5 свободных направлений.
- **Интеграция с существующей механикой корабля**:
  - Собранный модульный корабль вычисляется в суммарные параметры: общая масса, тяговооруженность, объём трюма, мощность выстрела, генерация энергии.
  - Игрок может экспортировать корабль в Галерею космических объектов (`SpaceObjectsGalleryModal`) и использовать его как активный флагман в симуляции!
- **Эргономика управления в 3D**:
  - Орбитальное вращение левой кнопкой мыши / тачем.
  - Зум колесиком мыши.
  - Подсветка узла при наведении (Hover Ghost Preview) с показом контура монтируемого модуля перед кликом.


### Спецификация типов данных:

```typescript
export type AxisDirection = '+X' | '-X' | '+Y' | '-Y' | '+Z' | '-Z';

export type ModuleCategory =
  | 'HUB_CORE'         // 6-лучевой стыковочный блок
  | 'ENGINE_SPHERE'    // Сфера с дюзой (реактивная, фотонная, ионная)
  | 'SOLAR_WINGS'      // Солнечные панели
  | 'SENSOR_RADAR'     // Приборы и радары
  | 'CARGO_BAY'        // Грузовые трюмы
  | 'WEAPON_MOUNT'     // Лазеры и плазма
  | 'COCKPIT_BRIDGE'   // Модуль пилота: рубка и каюта
  | 'LANDER_MODULE';   // Посадочный модуль

export interface ShipModuleSlot {
  id: string;
  axis: AxisDirection; // Направление относительно родительского хаба
  moduleType: ModuleCategory | null;
  subType?: string;    // 'NOZZLE_REACTIVE' | 'NOZZLE_PHOTONIC' | 'NOZZLE_ION' и т.д.
  childHubId?: string; // Если пристыкован другой хаб
}

export interface HubNode {
  id: string;
  gridPos: [number, number, number]; // Дискретные координаты в сетке хабов [x, y, z]
  slots: Record<AxisDirection, ShipModuleSlot>;
}
```

## 5. План выполнения (Этапы)

1. **Создание ядра конструктора (`src/components/ShipyardBuilderModal.tsx`)**:
   - Математика 3D-проекции составного графа модулей с честным расчётом мировых координат каждого блока.
   - Отрисовка центрального хаба (сфера + 6 туб) и всех типов навесных модулей.
2. **Реализация каталога компонентов и логики сборки**:
   - Подключение всех типов дюз (реактивная, фотонная, ионная).
   - Поддержка цепочек хабов (канонический корабль пользователя из 6 секций).
   - Панель живой телеметрии характеристик (масса, тяга, энергия, оружие).
3. **Кнопка вызова Верфи в главном интерфейсе и в галерее**:
   - Добавление кнопки «ВЕРФЬ / СБОРКА КОРАБЛЯ» в навигационную панель и интеграция с сохранением чертежей.
4. **Тестирование и верификация**:
   - Проверка сборки корабля точно по сценарию пользователя, проверка линтинга и сборки проекта.
